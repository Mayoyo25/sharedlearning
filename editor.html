Paste a list

One item per line. Use Title - description, Title: description or Title | description. Bullets and numbers are removed. Up to 15 items.

Import from JSON

Paste JSON or pick a file. Accepts a plain object, a bare array of items, or a JSON-RPC 2.0 envelope (reads params.arguments, params or result).

Format 
{
  "headline": "Top 5 Dev Tools",
  "subtitle": "What I use daily",
  "template": "dark",
  "palette": "midnight",
  "handles": [
    { "platform": "linkedin", "text": "@yourname" },
    { "platform": "x", "text": "@yourname" }
  ],
  "items": [
    { "title": "Notion", "description": "Docs and wikis", "icon": "auto" },
    { "title": "Figma", "icon": "logos:figma" },
    { "title": "Linear", "icon": "🚀" }
  ]
}

Item icon: an emoji, "auto" (match by title), "brand:Name", an Iconify id like "logos:figma", or an image URL / data URL. Optional top-level keys: kicker, footer (one text line) or handles (up to 4 strings or {"platform":"linkedin","text":"@name"}; platforms: linkedin, x, instagram, facebook, youtube, tiktok, threads, bluesky, github, substack, medium, mastodon, pinterest, reddit, website, email), font (a typeface name from the picker, e.g. "Poppins"), ratio ("4:5", "1:1", "9:16", "2:3", "16:9", "1.91:1"), colors (accent, background, text), show (kicker, numbers, descriptions, footer, icons).
