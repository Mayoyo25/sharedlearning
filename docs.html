How to use SharedLearning

Everything you need to make, style and export a list graphic, plus the details for developers who want to host or automate it.

Quick start

  1. Open the template gallery and click Use template, or open the blank editor.
  2. Click any text on the canvas and type. Press Enter in an item to add another one.
  3. Drag the number badge of an item up or down to reorder.
  4. Click Download PNG in the top right. Use the arrow next to it for JPG, PDF, copy to clipboard, or JSON.

The editor shows a short guided tour the first time you open it. Replay it any time with the ? button in the top bar, or Take the tour in the tips strip.

Templates and sizes

Open Template & size in the sidebar. Six layouts are available: Editorial, Dark Tech, Bold Cards, Clean Split, Magazine and Neon List. Choosing one also applies its default colors and type sizes.

Size Ratio Export (px) Use for
Portrait 4:5 1080 × 1350 LinkedIn, Instagram, Facebook feeds
Square 1:1 1080 × 1080 Any feed, X
Story 9:16 1080 × 1920 Stories, Reels, TikTok, Shorts
Tall 2:3 1080 × 1620 Pinterest
Wide 16:9 1920 × 1080 Slides, YouTube thumbnails
Banner 1.91:1 2060 × 1080 Link previews, cover images

On wide formats, or when a list is long, items flow into two or three columns automatically. If everything still does not fit, the text shrinks until it does.

Editing text

Everything on the canvas is editable in place: the top label, headline, subtitle, and each item's title and description. Pasted text is inserted as plain text on one line.

  • Use Elements in the sidebar to hide the top label, numbers, descriptions or the footer.
  • If your headline starts with "Top" and a number, the number updates when you add or remove items.
  • Your work autosaves in this browser. The top bar shows Saved on this device when it is done.

Items and reordering

  • Add: press Enter inside an item, or use + Add item below the canvas. The limit is 15 items.
  • Reorder: drag the number badge, or press Alt + ↑ / Alt + ↓ while editing an item. On a phone, press and hold the badge briefly, then drag.
  • Item toolbar: hover or tap an item to see buttons for move up, move down, icon, duplicate and delete.
  • Delete: press Backspace in an empty title, or use the toolbar. At least one item is always kept.
  • Paste a list: Import → Paste a list turns one line per item into items. Use Title - description, Title: description or Title | description to add a description. Bullets and numbers are removed. Choose to replace the current items or add to them.

Icons and logos

Each item can have an emoji, a brand logo or your own image. Click the icon in an item, or use the icon button on the item toolbar.

  • Search logos: type a brand name such as Notion, Figma or Stripe. Results come from the open Iconify logo libraries.
  • Match brand logos: in Icons in the sidebar, this looks up every item title and fills the icons in one go. Titles that are not brands are skipped.
  • Your own image: drop an image on an item, paste one while an item is selected, or use Upload logos… to fill several items in order. Images are resized to a small size and stored in the page.
  • Empty slots: an item with no icon shows a faint + in the editor so you can click it. The + never appears in exports.
  • Show or remove all: use Show item icons to hide every icon at once, or Remove all icons to clear them.
  • Brand mark: the sidebar's Brand mark adds a small symbol or your own logo at the right end of the footer.

Brand logos belong to their owners. Check each brand's guidelines before using them commercially.

Colors and typefaces

  • Colors: choose a palette (Warm, Ocean, Forest, Violet, Sunset, Crimson, Mono, Midnight, Neon), or set the accent, background and text colors yourself.
  • Type & size: pick from 49 typefaces, 47 of them open-source Google Fonts. Search by name or browse by group: sans serif, bold and display, serif, monospace, handwritten and system. Fonts load when you pick them.
  • Sizes: sliders set the headline, item, footer and icon sizes. Auto-fit still shrinks the text if the list would overflow.

Footer and handles

Add up to four handles under the list, for example your LinkedIn and X names. Each can have a platform icon.

  • Edit them on the canvas, or in Footer & handles in the sidebar.
  • Click a platform icon to change it. Sixteen platforms are built in, including LinkedIn, X, Instagram, YouTube, TikTok, GitHub and a generic website or email icon, plus None.
  • The footer is always one line. Each extra handle makes the text a little smaller, and very long handles shrink further.
  • Press Enter in a handle to move to the next, or add one. Backspace in an empty handle removes it.

Highlighting part of a text

Select some words in the headline, subtitle, top label or an item. A small dark bar appears above the selection:

  • Color dot: sets the color of the selected words.
  • Font menu: sets a different typeface for just that selection, or Default font to go back.
  • Clear: removes the formatting from the selection.

Press Esc or click elsewhere to close the bar. Highlights are saved and exported. They are not part of JSON import and export, which carries plain text only.

Annotating

Click Annotate in the top bar to open the drawing tools: line, arrow, box and circle, plus a color dot and delete.

  • Pick a tool, then drag on the canvas. The tool switches off after each shape.
  • Hold Shift while drawing to snap lines to 45° or make boxes and circles square.
  • Click a shape to select it. Drag it to move, or drag an end handle to resize. Change the color dot to recolor it.
  • Press Delete to remove the selected shape. Esc cancels a tool.
  • Shapes undo and redo, are saved with your work, and appear in PNG, JPG and PDF exports. Selection handles do not.

Importing

Open the Import menu in the top bar.

  • Paste a list: one item per line.
  • Paste JSON: an object, a bare array of items, or a JSON-RPC 2.0 envelope.
  • Upload JSON file: or drop a .json file on the canvas.

JSON format

{
  "headline": "Top 5 Dev Tools",
  "subtitle": "What I use daily",
  "kicker": "The stack",
  "template": "dark",
  "palette": "midnight",
  "ratio": "4:5",
  "font": "Inter",
  "handles": [
    { "platform": "linkedin", "text": "@yourname" },
    { "platform": "x", "text": "@yourname" }
  ],
  "show": { "icons": true, "numbers": true, "descriptions": true, "footer": true },
  "items": [
    { "title": "Notion", "description": "Docs and wikis", "icon": "auto" },
    { "title": "Figma", "icon": "logos:figma" },
    { "title": "Linear", "icon": "🚀" }
  ]
}

Only items is required. Each item needs a title. Other keys are optional.

Key Values
template editorial, dark, cards, split, magazine, neon
palette warm, ocean, forest, violet, sunset, crimson, mono, midnight, neon. Or colors with accent, background, text.
ratio 4:5, 1:1, 9:16, 2:3, 16:9, 1.91:1
font Any typeface name from the picker, such as Inter or Playfair Display
handles Up to 4 strings, or objects with platform and text. Platforms: linkedin, x, instagram, facebook, youtube, tiktok, threads, bluesky, github, substack, medium, mastodon, pinterest, reddit, website, email. Common aliases like twitter work. A single footer string is also accepted.
item icon An emoji; "auto" to match by title; "brand:Name"; an Iconify id such as "logos:figma" or "simple-icons:notion"; or an image URL or data URL

JSON-RPC

For tool integrations, the same data can arrive inside a JSON-RPC 2.0 envelope. The importer reads params.arguments, then params, then result, and understands MCP-style content[0].text and structuredContent.

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "make_list_graphic",
    "arguments": { "headline": "Top 3 Habits", "items": [{ "title": "Read" }, { "title": "Write" }, { "title": "Ship" }] }
  }
}

Exporting

  • Download PNG: the main button. Rendered at twice the design size.
  • More options (the arrow): Copy image to the clipboard, Download JPG, Download PDF (one page, sized to the graphic), and Download JSON to save an editable version you can import later.
  • Editing aids such as the item toolbar, empty icon slots, annotation handles and the highlight bar never appear in an export.

Exports use the fonts loaded in your browser at that moment. If you just changed typefaces, wait a second for them to load before downloading.

For developers

Files

index.html    landing page and template gallery
editor.html   the editor (one self-contained file)
docs.html     this page
README.md     overview and setup
LICENSE       MIT

Run it

python3 -m http.server 8080
# then open http://localhost:8080

Any static host works: GitHub Pages, Netlify, Cloudflare Pages, S3 or your own server. There is no build step. Keep the three HTML files in the same folder, because they link to each other by relative path.

Start from a template via URL

editor.html?start=KEY loads a starter. Keys: habits, tools, books, courses, exam, focus. If there is saved work in the browser, the user is asked before it is replaced.

Scripting API

await ListGraphic.load(jsonOrObject)   // same formats as Import; resolves true on success
ListGraphic.get()                      // current graphic in the JSON format above
await ListGraphic.start('tools')       // load a starter template

Libraries and services

  • SortableJS 1.15.2 for drag reorder
  • html2canvas 1.4.1 for image export
  • jsPDF 2.5.1 for PDF export
  • Google Fonts for typefaces, loaded on demand
  • Iconify API for brand-logo search (logos and simple-icons sets)

The three libraries load from cdnjs. To work without CDNs, download them and change the three <script> URLs in editor.html.

How it is built

  • Vanilla JavaScript in one function scope, with a single state object, a 50-step undo history and autosave to localStorage.
  • The graphic is a fixed-size element scaled with a CSS transform. Export renders a clone at its natural size.
  • Inline formatting is stored as sanitized HTML next to the plain text, and falls back to plain text if the two ever disagree.

Privacy and data

  • Your lists, images and annotations are stored only in your browser's local storage. Clearing site data removes them. Use Download JSON for a backup.
  • There is no account and no analytics in the code. Nothing you type is sent to a server by this app.
  • Network requests: the page loads libraries from cdnjs and fonts from Google Fonts. Logo search and Match brand logos send the name you searched to the Iconify API and download the matching logo.

Troubleshooting

Logos are not found, or "icon service unreachable"
Logo search needs access to api.iconify.design. Check your connection or ad blocker, or add an image yourself.
The exported text looks like a different font
The typeface had not finished loading. Wait a second after choosing it, then export again.
My work disappeared
Work lives in this browser's storage. Private windows, a different browser or cleared site data start fresh. Download JSON regularly to keep a copy.
Copy image does not work
Some browsers limit clipboard images. Use Download PNG instead.
The text is very small
Auto-fit shrinks text to fit long lists. Remove descriptions, use a wider or taller size, or reduce the number of items.
Something looks broken after an update
Hard refresh the page. If saved work is the cause, clear this site's local storage and re-import your JSON.
